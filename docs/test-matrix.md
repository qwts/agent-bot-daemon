# Test coverage matrix

Coverage this repository must grow as the daemon (HQ) and its plugins are
built out under [docs/daemon-plugin-split.md](daemon-plugin-split.md) —
the split of
[ADR-1183](https://github.com/qwts/agent-bot-identity/blob/main/docs/decisions/ADR-1183-agent-bot-splits-into-hq-and-plugins.md)
and [ENG-0111](https://github.com/qwts/qwts-agent-sop/blob/main/docs/decisions/ENG-0111-agent-bot-runtime-hq-daemon-and-plugins.md)
(issue #1). There is no code yet, so every row is a test the plan requires;
the Unit tests and E2E cells name the migration-table PR (§9) that owes them.
Priority: **P0** blocks the security goal or is itself a security property,
**P1** is needed before launch, **P2** as time allows.
